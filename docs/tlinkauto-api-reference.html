API JavaScriptCore & tương thích TrollStore

Trang tĩnh này tổng hợp các API public dùng trong script main.js, cách gọi, demo ngắn và trạng thái trên runtime TrollStore hiện tại.

● Có trên TrollStore ▲ Có nhưng hạn chế ◆ Experimental × Không có trên TrollStore
Ổn địnhCore automationtouch, screenshot, color, frame, image, Tesseract OCR, storage
Thử nghiệmZoom / UI Treeđã có API nhưng còn chờ promotion thiết bị
Hạn chếSpringBoard-onlykeyboard visibility, global touch indicator, true boot start
Khác rootfullModule helpersrequire/include/manifest và vài helper TLinkauto chưa có ở facade TrollStore
Lưu ý runtime: iOS on-device hiện dùng JavaScriptCore. Python playback đã bị loại khỏi package/runtime; các file Python trong repo chỉ còn tính chất legacy/dev tooling.

Cách đọc kết quả API

Phần lớn API native trả object chuẩn hóa có ok, code, payload, raw và thêm field đã parse khi có thể.

var r = device.pickColor(100, 200);
if (!r.ok) {
  console.log("Lỗi: " + (r.error || r.payload || r.raw));
} else {
  console.log("RGB =", r.red, r.green, r.blue);
}

Runtime

Module loader & manifest

TrollStore: không có
require(path)include(path)manifestsleep(ms)

Rootfull JavaScriptCore có CommonJS-like loader, include, manifest object và global sleep. Facade TrollStore hiện không cài các global này.

require("./lib") · include("./common.js") · manifest.name · sleep(250)
// Rootfull
var util = require("./lib/util");
include("./common.js");
console.log(manifest.name);
sleep(250);

// TrollStore thay sleep global bằng:
device.sleep(0.25);
Trên TrollStore hãy giữ script tự chứa trong main.js hoặc dùng storage/file APIs thay vì trông chờ require/include.
Nguồn: pccontrol/jsruntime/TLinkJSRuntimeCore.mm; stream-app/streamd/POCSocketServer.mm
Runtime helper

Helper TLinkauto của rootfull

TrollStore: không có
TLinkauto.assertTLinkauto.ensureOkTLinkauto.retryTLinkauto.withFrameTLinkauto.withImageTLinkauto.withCapturedImage

Các helper tiện ích này được inject ở rootfull runtime. TrollStore chỉ dùng object TLinkauto cho Smart Wait, không có nhóm helper này.

// Rootfull
var shot = TLinkauto.ensureOk(device.screenshot(), "screenshot failed");
TLinkauto.withFrame({ bgra: true }, function(frame) {
  console.log(device.framePickColor(frame.id, 10, 10, {}));
});

// TrollStore: kiểm tra ok và release thủ công
var frame = device.captureFrame({ bgra: 1, gray: 0 });
try {
  if (!frame.ok) throw new Error(frame.error || frame.raw);
} finally {
  if (frame.ok) device.releaseFrame(frame.id);
}
