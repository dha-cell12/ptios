# D01a — Capture preparation and ownership package

Date: 2026-11-07 (Asia/Bangkok). Baseline: `c9a54d5f`; user reported C05ae built successfully and requested larger implementation batches. Rootfull/roothide Screen/Common and production TrollStore StreamCaptureSource; TouchPOC excluded. Advances P1-22/D01, arithmetic/failure safety and temporary ownership while keeping the qualified fresh-surface backend.

## One batch across both capture producers

1. Root caches only the hardware-class rotation decision. Preserve the preceding regular expression exactly, including its historical alternatives, rather than replacing it with a different model parser. An atomic three-state memo distinguishes unknown from false/true. Publish after a successful nonempty model/regex computation; nil/empty/failed computations retry and exceptions cannot publish a value. Cold concurrent probes can duplicate work before one winner publishes. No device-name string, orientation, bounds, scale or captured pixels are cached by this memo.
2. Bound the Common uname consumer: initialize the struct, require uname success and a nonempty NUL-terminated machine field inside its capacity, then construct UTF-8 using the checked length. Ordinary valid device strings remain equal to the preceding helper. Unavailable, empty, unterminated or invalid UTF-8 returns nil; previously failed uname could expose uninitialized memory. Root treats an unavailable model as a non-rotated capture for that attempt and retries the classification later.
3. Root and TrollStore factories reuse immutable IOSurface properties through separate four-entry FIFO caches. Keys include live width, height, stride, exact allocation, global flag and signed-dimension boxing variant. Validate before lookup; create outside the cache mutex, recheck before publication and hold the result strongly after unlock. Readers survive replacement/cache destruction; factory nil/fault is uncached and recoverable. Cold races may duplicate a dictionary build; only four completed entries are retained per factory. All seven property values and the root-size_t/TrollStore-int dimension boxing expressions remain.
4. TrollStore keeps global creation as the first attempt on every call. On kernel creation failure, request a separate immutable non-global dictionary and retry once. The global dictionary is never mutated or disabled by a prior failure. Cache only preparation metadata: every fresh capture still creates a fresh source IOSurface; source/staging pools, accelerator opt-in, coherence, pixel copy, keep-screen and backend/status contracts remain unchanged.
5. Read one UIScreen instance per TrollStore size query, with fresh scale/bounds each time. Check finite positive products and rounded int boundaries before casting, preserving ordinary llround/min/max results. Check BGRA minimum stride, 128-byte fallback alignment and allocation multiplication without the preceding int-roundup overflow. Preserve valid alignment returned by IOSurfaceAlignProperty; reject overflow before property creation/IOSurface calls. This is arithmetic validation, not a new allocation-byte quota or target-resolution backend.
6. Share an owned fresh-surface transaction across root and TrollStore. Require a successful lock before render; own the image through validation/rotation/unlock; discard zero-dimension images and failed-unlock results; release every known owner on normal refusal or reached NS/C++ unwind. Unlock only acquired surfaces and never repeat an explicit unlock attempt. Root's borrowed color space stays owned by the source/context; a scoped context now survives transform/draw/image-creation exceptions. Cleanup C APIs are expected to be nonthrowing. Unreturned allocations inside opaque producers cannot be recovered by a consumer.
7. Root scopes complete capture preparation in a normal pool and returns the owned CF image across it. Normal success/failure retires preparation/provider temporaries before return. Existing caller-owned CF references keep the result alive; no pixel/image/surface is placed in the metadata cache. Exception-exited Clang pools are not assumed to drain.
