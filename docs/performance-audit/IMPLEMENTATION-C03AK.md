## Delivered together

- Start selection after the cursor using a checked upper-bound search. A cursor before the first event keeps the direct fresh-page path; a fully consumed snapshot needs one tail probe instead of walking every event. The private batch helper receives ordered snapshots from the existing checked journal reader/cache; no validation is skipped on untrusted input.
- Reserve the selected-array hint from the eligible tail, request limit and existing32-entry initial cap. Fully consumed snapshots reserve zero entries. Selection still uses the unchanged TLinkEventBatchCursor policy, so filtered tails, omitted matching events, next_cursor, has_more and gaps retain their preceding behavior.
- Recognize empty/wildcard topic sets once when eligible rows exist. The wildcard path avoids per-row topic probing. Specific-topic filters retain the existing matcher, now applied only to the newer tail. Internal topic sets are the existing owned immutable request sets; no request/cursor syntax or topic policy changes.
- Count JSON payload bytes through a synchronous NSOutputStream sink that retains no chunks. On a coherent successful stream write, the producer no longer asks for a complete NSData solely to decide whether to return its original payload or the existing truncation metadata. Count the whole representation to preserve exact original_bytes, including Unicode, NUL escaping and nested/numeric output. Keep the4096-byte payload policy and original object identity below the limit.
- Preserve the exact preceding dataWithJSONObject path as fallback when counting fails, reports inconsistent bytes, closes unexpectedly or throws an NS/C++ exception. The sizing optimization performs no file/socket writes; fallback does not replay an external effect. Original encoder failures/throws retain their preceding publication handling. A sticky checked byte counter refuses arithmetic overflow and incomplete stream results never become successful sizes.
- Scope payload preparation and normal counting temporaries to local pools, with finally close for the stream. Count helper out parameters are scalar; NSError stays local to its write scope. The private stream lives in an include used only by the event implementation, so existing Makefile entries compile it without adding another component or coupling events to AX/native budgets.

The journal parser/validation/cache, generation/probe cadence, process/flock scope, event field/sequence assignment, publish commit/unlock/notify order, cancellation/admission/timers and wire encoders remain unchanged. Payload work still occurs in its original publication position; full journal serialization/atomic replacement remains. No new cache, deadline, durability guarantee or output field is introduced.
