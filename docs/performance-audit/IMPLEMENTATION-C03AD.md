# C03ad — Shared event/history preparation and publication lifetime

Date: 2026-11-07 (Asia/Bangkok). Baseline: `9da1965a`; user reported C05af built successfully and requested larger implementation batches. Scope: shared event channel and run history used by rootfull/roothide and production TrollStore. TouchPOC excluded. P1-48/P1-54 remain partial because complete index/journal read/parse/rewrite still occurs.

## Six changes in one checkpoint

1. Event runtime/topic/type tokens use a bounded 64-unit stack buffer and one final NSString construction. Keep Foundation lowercaseString before filtering, ASCII allowlist, dropping invalid UTF16 units, 64 accepted-unit cutoff and original fallback. Remove per-character appendFormat and per-call character-set construction. Lowercasing and scanning a long invalid prefix remain proportional to input length.
2. History run-name sanitization uses a bounded 96-unit stack buffer and one final NSString. Keep case, ASCII allowlist, replacement of each invalid UTF16 unit with underscore, first-96-unit cutoff and `run` fallback. Remove source-length mutable capacity, per-unit NSString construction and append calls. Unicode surrogate pairs still produce two replacement units, preserving the preceding path text.
3. Persisted journal NSNumber validation accumulates checked uint64 during the existing ASCII digit scan. Keep CFBoolean rejection, nonempty stringValue, nondigit priority, null-result refusal, unchanged failed output, overflow refusal and errno behavior for ordinary Foundation numbers. Remove the second UTF8String/strtoull conversion. The public cursor parser stays unchanged; no new cursor syntax is admitted. The removed opaque UTF8 conversion can no longer introduce an encoding-allocation failure on an otherwise valid decimal.
4. Batch selection preallocates at most min(requested limit, available events, 32) array slots. This bounds the capacity hint, not the private helper's selection limit: larger private limits can still grow the array. Preserve graph fields, gap/cursor/filter/timeout semantics and selected event identities.
5. A normal per-publication autorelease pool scopes journal, serialization and other unreturned temporaries. The existing process lock/file flock, checked read, sequence exhaustion, event construction, atomic write, finally unlock, failure replies and notification ordering remain. Both locks exit before normal pool retirement; notification still follows commit/unlock. Returned event/payload values remain owned across the pool.
6. A normal status pool scopes read/batch/format temporaries. Keep complete status/error schema and counters. Returned graphs cross the pool; LoadSnapshot and other out-parameter helpers do not acquire independent inner pools that could invalidate their error/fingerprint outputs.

The token/sanitizer now return an immutable NSString for nonempty output, whereas the private preceding helper returned a mutable builder. Logical token/name/path values and public schemas are preserved; no public mutability contract is added. Publication payload reference behavior remains unchanged. No persistence format, durability, sequence, polling cache, lock admission, authority, transport or notification protocol changes.
