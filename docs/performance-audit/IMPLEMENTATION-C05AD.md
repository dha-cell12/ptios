# C05ad — Batched AX probe cancellation and resource cleanup

Date: 2026-11-07 (Asia/Bangkok). Baseline: `16ea23c1`; user reported C05ac built successfully and requested more implementation per build checkpoint. Shared rootfull, roothide and production TrollStore code; TouchPOC excluded. Continues C05 / P1-59, P1-60, P1-61 and P2-23.

## Seven connected changes in one package

1. **Notify token ownership.** Capture the entry budget, skip registration if already stopped and skip/get/refuse state across observed stop. Every successful registration reaches notify_cancel through finally, including a state-read NS/C++ exception. Registration failures keep the prior false result. Normal API call/status/value behavior stays unchanged; tokens and lock values are not cached.
2. **Lock probe stages.** Capture the caller through both notifications, cached symbol resolution, server-port lookup and lock RPC. Refuse observed late state and skip later probe groups. Internal stopped lock reads return nil; existing snapshot/hit-test wrappers already gate stop immediately afterward, and capability now does likewise. Lock/allow_locked/action guards remain unchanged. The original lock-RPC NSException fallback remains.
3. **Entitlement cleanup.** Refuse stopped entry, post-resolution, post-task creation and post-value copy. A newly created one-off task is released even when creation consumes the remaining caller budget. A shared task remains with the capability finally owner. Late value/error objects are released without publishing a successful entitlement. Keep missing-symbol/create retry, fresh values and BOOL normalization.
4. **Capability lifecycle.** Capture the caller before prepare; gate between prepare, lock, foreground and each of the three entitlement reads. A stopped probe returns the existing UI error envelope: OutputLimit retains ui_response_too_large; cancellation/deadline retain ui_cancelled_or_timed_out. Keep full ordinary capability schema/keys/provider order, one shared Security task and the reached-provider exception behavior. Per-key normal pools retire temporary values while preserving the immutable BOOL result. No new deadline or authority relaxation.
5. **SBS foreground consumers.** Gate captured stop through first/second/legacy providers. Protect each retained Copy result with finally around Foundation copy, including NS/C++ copy faults and late stop. Validate a NUL exists inside the legacy 512-byte buffer before stringWithUTF8String. Keep first-success order, lazy second-symbol lookup, live reads, mutable-input snapshots and ordinary error/CF behavior.
6. **Direct AX foreground stages.** Gate entry, loader/class/server/PID selectors, system-app flag and each metadata/fallback group. Split system-app PID scan from its context lookup so an observed stop does not enter the next provider. Preserve focused/top-event/system-app precedence, diagnostics, nil/error handling, executable/hidden-app guards and all public target/completeness/action checks. No additional fallback retry or committed action replay.

7. **Captured public/SpringBoard foreground wrappers.** Retain the entry budget once through selector/main/fallback work and reuse it for stop classification instead of repeatedly reading ambient TLS. A provider leaving unrelated TLS cannot hide cancellation of the original caller. Keep C05ac main bridging, public fallback order, live errors and all target guards. Extend the existing foreground runtime executable with cancellation/output tests across seven wrapper stages under changed TLS.
