# D01b — Bitmap resource package

Date: 2026-11-07 (Asia/Bangkok). Baseline: `d5f08d35`; user reported D01a built successfully and requested larger implementation batches. Scope: rootfull/roothide Image.xm and production TrollStore CaptureCore/StreamCaptureSource. Advances P1-22/D01 with seven connected changes in one checkpoint; TouchPOC excluded.

## Changes

1. Share a successful immutable DeviceRGB color space within each process across bitmap consumers. An atomic owned-reference memo publishes one winner, drops losing cold candidates and retries failed creation. Creation occurs outside a mutex and supports reentry. Consumers borrow the pinned result; CoreGraphics contexts/images keep their usual references. The root gray adapter still prefers its input image's color space. Geometry, source images, surfaces and rendered pixels remain live per call.
2. Root BGRA and gray renderers own each created CGContext immediately, including draw/conversion unwind. Preserve context flags, stride, zeroing, channel layout and conversion algorithm. Contexts remain per call; this package does not pool mutable CGContext instances.
3. Root frame capture owns its screenshot before geometry, reservation, frame allocation, metadata and rendering. Reached NS/C++ unwind releases the source and pending memory reservation. Normal release points, TTL, owner fields, admission, publication and replies remain.
4. Root Vision's CGDataProvider immediately owns its frame reader through a scope guard. Failed or throwing image/color creation releases the provider and its held ledger charge; successful CGImage ownership still retains its source reader after store release. Existing ROI/age/stop policy remains.
5. TrollStore production capture materialization uses one shared zeroed-byte owner across the producer and NSData deallocator. A nil/throwing factory cannot orphan the raw allocation. An early deallocator callback does not free bytes while the producer still holds them; the final shared owner frees exactly once. Validate returned NSData length/bytes and classify from its published bytes, allowing a copying factory without reading retired producer memory. Source/context/provider/detached-image owners cover reached unwind. A normal per-capture pool retires temporaries before return; returned NSData/UIImage remain owned by the outcome. Exception-exited pools are not assumed to drain independently.
6. TrollStore CoreGraphics-to-CVPixelBuffer copy checks row/geometry arithmetic, owns the successful base-address lock and the context, and unlocks on refusal/NS/C++ unwind. Keep BGRA flags, target dimensions and drawing behavior. The prior unlock-result policy is unchanged.
7. Streaming owns its CPU capture mutex and each returned source/retry CGImage through normal and exception exits. Explicit unlock/image-release timing remains at the preceding success/failure points. The default fresh-surface backend, requested-mode behavior and diagnostics remain. The opt-in private accelerator's borrowed IOSurface/kernel lock paths are separate and are not fully exception-qualified by this package.

The byte control block/deallocator and scope guards add bookkeeping. Color creation is removed from warm calls, but no FPS, CPU, latency or RSS improvement has been measured. No target-size/direct-gray backend, source-surface reuse or pixel cache is introduced.
