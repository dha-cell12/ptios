Date: 2026-11-07 (Asia/Bangkok). Baseline: `4fb23484`; user reported C03ak build passed and requested larger batches. Scope: shared FileHandle plus rootfull/roothide, helper and production TrollStore open-file frontends. TouchPOC excluded. Extends P1-43/P1-44/P1-47 preparation and ownership work.

## Delivered together

- Add a stack/value C++ mode plan with a private constructor and read-only accessors. Only the existing Foundation normalizer/accepted-mode policy can produce it. The plan owns an immutable NSString copy, validity, writing/plus state and kernel flags; it does not allocate another NSObject wrapper or cache values across calls.
- Each of the three frontends prepares once, uses that plan's writing state for its existing path/permission decision and passes the same plan to open. Ordinary valid opens reduce normalizer entries from three to one, removing repeated lowercase/trim and duplicate mode validation work. Preserve all accepted modes/aliases/defaults and canonical metadata.
- Keep the raw mode-based API and both existing public validation helpers. Extract the physical open, metadata repair, append positioning, construction, capability probes, final fd handoff and finally retirement into one private class method shared by raw/prepared routes. Its body remains exactly equal to the preceding implementation. Invalid plans refuse before any kernel open.
- Seal the mode used for authority and flags. A mutable argument changed from r to w+ inside path resolution previously passed a read-only policy decision and then re-normalized to writable/truncating flags. The prepared route continues using the owned r snapshot and opens read-only. This is an intentional consistency fix for reentrant/mutable native arguments; ordinary JS strings retain their preceding behavior. It relies on NSString's immutable-copy contract, not a cross-request cache.
- Add normal local pools to all nine emitted JS callbacks: read, readLine, write, writeBase64, seek, tell, flush, isClosed and close. Conversion/preparation now retires with the call while returned graphs remain owned. Preserve defaults, argument conversion/cast order, forwarded methods and close-before-didClose behavior.
- Scope JS object/metadata/block preparation to a normal creation pool. Returned JSValue/attached blocks retain the same handle/closures and metadata. No new exception translation or retry is added; close/callback committed effects remain committed when a later callback throws.

The existing context/session checks, mode-error priority, path policy, directory preparation, file-count/ID handling, weak close bookkeeping and helper storage-op count keep their source and order. The additional prepared selector is C++-only in the header; existing Objective-C/raw API remains available. Full data/base64 replies, payload/line/seek/flush/close algorithms and IO/durability choices remain unchanged.
