# C03ac — Shared FileHandle payload and operation lifetime package

Date: 2026-11-07 (Asia/Bangkok). Baseline: `9025da31`; user reported A02b built successfully and requested larger batches. Scope: the shared FileHandle used by rootfull/roothide, helper and production TrollStore. Advances P1-43/P1-47 and temporary ownership while retaining P1-44's complete dual text/base64 reply contract. TouchPOC excluded.

## Changes in one checkpoint

1. `readRequest` grows its NSMutableData and lets POSIX read directly into the writable tail. Reacquire mutableBytes after each growth; no pointer survives another growth. Keep the preceding 8192-byte request quantum, partial-read/EINTR progression and configured transfer limit. Trim to the actual byte count before formatting a success. Remove the intermediate stack buffer and append copy; Foundation growth/zeroing/reallocation can still occur.
2. Share checked portable read progress. No addition exceeds the remaining limit. EOF still means an observed zero read; reaching the exact limit does not probe an extra byte. Preserve numeric/all/line selection, zero-byte request, EOF/truncated flags, binary/UTF8 decoding, file positions and error-prefix behavior. A missing growth buffer fails with ENOMEM before issuing read; an impossible overreturned count fails with EIO and publishes no prefix.
3. Share checked write progress without replay. Preserve partial writes, EINTR, the explicit zero-write error, ordinary errno diagnostics, admission order, returned byte count and successful descriptor effects. Reject a positive count larger than the remaining request with EIO and a nonempty null buffer with EFAULT. Negative returns with no errno use EIO. These are additional refusals for malformed providers; ordinary POSIX behavior retains the preceding replies. An error after partial IO does not roll back file contents or position.
4. `writeText` reuses the existing retained immutable UTF8-view helper. Borrow only an already available internal CF UTF8 pointer; retain the immutable snapshot through the data wrapper. Otherwise keep Foundation encoding. Embedded NUL uses the full byte length, not strlen. Mutable strings are snapshotted; nil/failed encoding retains the preceding empty-data fallback. Encoding still occurs before closed/writable/size admission, preserving ordinary error priority. No text/base64 field is removed, and base64 decoding/options are unchanged.
5. Scope normal `readRequest`, `readLine`, `writeText` and `writeBase64` temporaries to a per-operation autorelease pool. Owned results and their text/base64/path fields cross the pool. Descriptor ownership and synchronization remain; the lock exits before normal pool drainage. The readLine chunk/rewind algorithm, regular-file selection, seek/tell/append/flush/close and JS binding source remain unchanged.

No frontend path resolver, authority check, storage operation counter, active-handle registry, codec signature or durability policy changes. All three production targets already link CoreFoundation. There is no new cancellation/deadline protocol; a blocking POSIX call or repeated EINTR remains subject to the preceding behavior.
