## Changes delivered together

- Replace the private formatted NSString fingerprint with a typed scalar stamp: device, inode, size, mtime seconds/nanoseconds, ctime seconds/nanoseconds, or missing-file errno. A separate empty state represents the old nil cache. Keep exactly the preceding identity fields, probe count, forced-hint reload, periodic metadata check and cache-clear/error behavior. The loader's private fingerprint out-parameter changes to a C++ value; the public header/API/schema stays unchanged. There is no content digest, new cross-request graph cache or stronger noncooperating-writer guarantee.
- Reuse directory preflight and post-flock validated lock stat fields to plan mode/owner repair. Skip chmod/lchown or fchmod/fchown when mode including special bits and UID/GID already match. Root0750, lock0640 and501/501 policy remains, with independent mode/owner attempts in the original order. Keep root/type/single-link/inode/no-follow/nonblocking/post-flock fences and descriptor targeting. Repair failures retain the preceding ignored-return behavior; this does not add an atomic permission protocol.
- Validate topics directly as bounded UTF16 ASCII units. Accepted ASCII still has the same64-byte limit, alphabet and single-star wildcard; every non-ASCII/NUL/invalid unit remains refused. Remove per-topic NSData/UTF8 encoding. Preserve timeout/limit/topic-count/error priority, comma handling, normalization and ordinary Foundation parser replies. A refused overlong topic needs no unit reads. Full request splitting/parsing still has its existing costs; arbitrary custom NSString method-call or allocation-failure timing is not promised identical.
- Pool each journal record's validation temporaries. Keep all persisted NSNumber/type/schema/sequence/timestamp/payload/nonempty-field checks and their order. The decoded graph and previous sequence stay owned outside the record pool; the next-sequence temporary can still live in the enclosing caller pool. Error/out-parameter readers retain their original enclosing scope.
- Pool each JSON journal write's encoding phase, retaining exact validation, byte cap, atomic write/permissions and acknowledgment. The phase can retire while the existing flock is held; publish still unlocks before notify and returns its owned event graph. Read/public-operation witnesses remain post-unlock. No write retry or replay is added.
- Pool each Sweep waiter iteration, including normal skip/cancel/timeout/completion paths. Callbacks receive their existing batch/error graph and may retain it across the pool. Keep the existing changed/expired gates, one owner/timer, authorization deadline, admission limits, cancellation release, callback order and rearm policy. No callback-exception policy change is introduced.
- Pool synchronous BeginPoll preparation. The returned request and queued blocks retain parsed topic set, completion, error and leases before temporary drainage. Queue scheduling, authorization, denial, cancellation and the compatibility blocking wrapper remain at baseline. No independent pool is added to the NSString error out-parameter path.

Typed stamps remove explicit fingerprint formatting/allocation, and warm permission repair sites can become zero calls. These source changes are not measured device CPU/RSS/IO gains. Encoded/decoded Foundation graphs and full journal read/parse/rewrite remain; temporary pools do not establish a total memory bound.
